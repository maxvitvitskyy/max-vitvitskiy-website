# Заявки з сайту → Google Таблиця + лист + Telegram

Сайт надсилає два типи заявок в один вебзастосунок Google Apps Script (проєкт «Orders»):

- **Замовлення** з вікна покупки (`js/checkout.js`) потрапляють на аркуш «Замовлення».
- **Звернення** з форми на головній (`tools/home.src.html`) потрапляють на аркуш «Звернення».

Обидва аркуші в таблиці «Замовлення картин — maxvitvitskiy.com». Про кожну нову заявку приходять лист на maxim.vitvitskiy@gmail.com і повідомлення в Telegram.

- Код скрипта: [`Code.gs`](Code.gs). Це копія версії 7. Редагують його в браузері, тож цей файл може відставати.
- Endpoint (публічний, не секрет) записаний як константа `ENDPOINT` в `js/checkout.js` і `tools/home.src.html`:
  `https://script.google.com/macros/s/AKfycbwgas3sSCdg5JE1-jCxaIyVmgAIy_qiVGggrydrz3rhjcOCyxb4HgcsRCmqhVCwcEoV/exec`

## Контракт

`POST` на endpoint. Тіло — JSON-рядок із заголовком `Content-Type: text/plain;charset=utf-8`.

Не використовуй `application/json` (браузер зробить CORS-preflight, який Apps Script не обробляє) і `mode:'no-cors'` (сайт не побачить відповіді й не зможе відрізнити успіх від збою).

### Замовлення (без `type`)

| Поле | Обов'язкове | Зміст |
|---|---|---|
| `order` | так | номер замовлення, генерується на клієнті: `MV-РРММДД-XXXX` |
| `work` | так | назва роботи |
| `email` | так | email покупця |
| `size`, `finish`, `frame`, `price_usd` | | конфігурація й ціна в USD |
| `name`, `phone` | | контакти |
| `country`, `city`, `delivery` | | доставка |
| `gift`, `gift_message` | | `gift`: «так» / «yes» тільки для подарунка; текст листівки |
| `payment`, `comment` | | спосіб оплати, коментар |

### Звернення (`type: "contact"`)

| Поле | Обов'язкове | Зміст |
|---|---|---|
| `name` | так | ім'я |
| `contact` | так | email або Telegram (якщо це email, «Відповісти» в листі йде на нього) |
| `message` | так | повідомлення |
| `topic` | | тема з форми, наприклад «Придбання з колекції» |

### Спільне для обох типів

- `lang` (`uk` / `en`): передавати завжди, за ним у Telegram ставиться прапорець.
- `url`: повна адреса сторінки з `https://`, інакше в Telegram не буде посилання.
- `website`: honeypot. Якщо він заповнений, скрипт мовчки відповідає `{ok:true}` і нічого не записує.
- `received` і `status` («Новий») ставить сервер.
- Значення, що починаються з `= + - @`, записуються як текст, тож формула з форми не виконається.

Відповідь: `{"ok":true}` при успіху або `{"ok":false,"error":"…"}` при помилці (`missing fields`, якщо бракує обов'язкових полів). `GET` повертає `{"ok":true,"service":"orders"}`.

Сайт показує успіх («Замовлення прийнято» / «Повідомлення надіслано») лише після `{ok:true}`. Інакше вікно покупки показує помилку з адресою пошти, а форма на головній відкриває готовий лист як запасний варіант.

## Telegram

Повідомлення розбите на блоки, порожні блоки не показуються:

- **Замовлення:** номер, робота (розмір, виконання, рама, ціна), клієнт, доставка (з подарунком), оплата, коментар.
- **Звернення:** тема, від кого, повідомлення.

Внизу кожного повідомлення є посилання на сторінку й на таблицю. Коментар, текст листівки й повідомлення показуються цитатою до 1500 символів, а в таблиці зберігаються повністю.

Токен і chat_id зберігаються тільки в **Project Settings → Script Properties** (`TG_TOKEN`, `TG_CHAT_ID`), ніколи в коді, на сайті чи в репозиторії. Спершу записується рядок у таблицю, тож збій Telegram або пошти заявку не губить. Перевірити бота можна функцією `testTelegram` у редакторі.

## Тестування

Тестові заявки підписувати іменем «ТЕСТ — видалити», номери замовлень починати з `TEST-`. Тестові рядки видаляє власник таблиці. Існуючі рядки не змінювати.

## Розгортання

1. Таблиця → **Розширення → Apps Script** → вставити код → зберегти.
2. Один раз запустити `setup`, щоб створити аркуші й надати дозволи (таблиці, пошта, зовнішні запити).
3. Після змін у коді оновити **наявне** розгортання: **Розгорнути → Керувати розгортаннями → ✎ → Версія: Нова версія**. Нове розгортання не створювати: зміниться URL `/exec`, і сайт перестане надсилати заявки.
4. Ліміт Google — близько 100 листів на добу для звичайного акаунта.
