# Замовлення → Google Таблиця

Вікно покупки на сайті (`js/checkout.js`) надсилає кожне замовлення у вебзастосунок Google Apps Script. Той записує рядок у таблицю «Замовлення картин — maxvitvitskiy.com» (аркуш «Замовлення») і надсилає лист на maxim.vitvitskiy@gmail.com.

- Код скрипта: [`Code.gs`](Code.gs). Це та сама версія, що розгорнута в проєкті «Orders».
- Endpoint (публічний, не секрет) записаний у `js/checkout.js` як константа `ENDPOINT`:
  `https://script.google.com/macros/s/AKfycbwgas3sSCdg5JE1-jCxaIyVmgAIy_qiVGggrydrz3rhjcOCyxb4HgcsRCmqhVCwcEoV/exec`
- Якщо `ENDPOINT` порожній, сайт відкриває замовлення як готовий лист у поштовій програмі покупця.

## Контракт

`POST` на endpoint. Тіло — JSON-рядок із заголовком `Content-Type: text/plain;charset=utf-8`.

Чому `text/plain`, а не `application/json`: з `text/plain` браузер надсилає простий запит без CORS-preflight. Preflight Apps Script не обробляє, тому з `application/json` запит не пройде.

| Поле | Обов'язкове | Зміст |
|---|---|---|
| `order` | так | номер замовлення, генерується на клієнті: `MV-РРММДД-XXXX` |
| `work` | так | назва роботи |
| `email` | так | email покупця |
| `size`, `finish`, `frame`, `price_usd` | | вибрана конфігурація й ціна в USD |
| `name`, `phone` | | контакти |
| `country`, `city`, `delivery` | | доставка (Нова пошта або адреса) |
| `gift`, `gift_message` | | подарунок і текст листівки |
| `payment`, `comment` | | спосіб оплати й коментар |
| `lang` | | `uk` або `en` |
| `url` | | сторінка роботи |
| `website` | | honeypot: має бути порожнім |

`received` і `status` (`Новий`) ставить сервер. Якщо `website` заповнене, скрипт мовчки відповідає `{ok:true}` і нічого не записує. Значення, що починаються з `= + - @`, записуються як текст, тож формула з форми не виконається.

Відповідь: `{"ok":true}` при успіху або `{"ok":false,"error":"…"}` при помилці (`missing fields`, якщо немає `order`, `email` чи `work`). `GET` повертає `{"ok":true,"service":"orders"}`.

Екран «Замовлення прийнято» сайт показує лише після відповіді `{ok:true}`. В іншому разі покупець бачить помилку з адресою пошти, а кнопка «Надіслати замовлення» знову активна для повторної спроби.

## Розгортання

1. Таблиця → **Розширення → Apps Script** → вставити `Code.gs` → зберегти.
2. Один раз запустити `setup`, щоб створити аркуш і надати дозволи (таблиці, пошта).
3. **Розгорнути → Нове розгортання → Вебзастосунок**: «Виконувати як: Я», «Доступ: Усі».
4. Після змін у коді: **Розгорнути → Керувати розгортаннями → ✎ → Версія: Нова версія**. Адреса `/exec` не змінюється, тож сайт оновлювати не треба.
